# 사용성 검증 시나리오

## 검증 대상

- 주요 사용자: 스마트폰 사용에 익숙하지만 작은 글자와 복잡한 운동 앱에 부담을 느끼는 50대 여성
- 목표: 설명 없이 오늘의 운동을 시작하고 안전하게 완료할 수 있는지 확인

## 과업과 성공 기준

| 과업 | 성공 기준 | 확인할 지표 |
| --- | --- | --- |
| 오늘 운동 시작 | 10초 안에 시작 버튼 선택 | 첫 클릭 성공, 소요 시간 |
| 안전 정보 확인 | 운동 전 무릎 부담 수준을 찾음 | 정보 발견 여부 |
| 운동 중 쉬기 | 도움 없이 일시정지 후 재개 | 오조작 여부 |
| 통증 대응 | 중단 안내의 의미를 설명 | 안전 문구 이해 여부 |
| 운동 완료 | 다음 동작을 거쳐 완료 화면 도달 | 흐름 이탈 여부 |
| 몸 상태 기록 | 세 상태 중 하나 선택 | 선택 의미 이해 여부 |

## 휴리스틱 자체 점검 결과

- 가시성: 진행률, 남은 시간과 현재 단계가 한 화면에 표시됨
- 일관성: 코랄은 핵심 행동, 세이지는 안전·긍정 상태에 사용됨
- 오류 예방: 통증 시 즉시 중단 문구를 운동 진행 화면에 상시 노출함
- 접근성: 큰 버튼, 높은 대비, 키보드 포커스와 상태 알림을 제공함
- 통제감: 이전, 일시정지·계속하기, 다음 이동을 제공함

실사용자 인터뷰 결과가 없는 상태이므로 위 내용은 설계 검증 시나리오이며 실제
사용성 테스트를 수행했다고 표현하지 않습니다.
