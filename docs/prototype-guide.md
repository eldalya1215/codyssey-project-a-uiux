# 프로토타입 실행 및 제출 가이드

## 로컬 프로토타입

`prototype/index.html`을 브라우저에서 열면 다음 흐름을 직접 확인할 수 있습니다.

1. `5분 운동 시작`을 선택해 운동 진행 화면으로 이동
2. `다음` 또는 중앙의 완료 영역을 선택해 완료 화면으로 이동
3. `내일 운동 확인`을 선택해 오늘의 운동 화면으로 복귀

각 화면의 주요 버튼은 키보드 포커스와 접근성 이름을 제공합니다. URL의
`#today`, `#progress`, `#complete` 해시로 특정 화면을 바로 열 수도 있습니다.

운동 진행 화면의 `잠시 쉬기`는 실제 일시정지 상태로 전환되며, 다시 선택하면
운동 계속 상태로 돌아옵니다. 브라우저의 뒤로가기와 `Esc` 키도 이전 화면 이동에
사용할 수 있습니다.

자동 화면 전환 검증은 프로젝트 루트에서 `node prototype/smoke-test.cjs`로 실행합니다.
검증 범위는 이미지 로딩, 전체 화면 순환, 일시정지 상태, 해시 직접 진입,
키보드 뒤로가기를 포함합니다.

## Figma 제출 마무리

1. Android 프레임 3개를 만들고 화면 이미지를 각각 배치합니다.
2. 이미지 위에 투명 Hotspot을 올려 로컬 프로토타입과 같은 흐름으로 연결합니다.
3. 시작 프레임을 `오늘의 운동`으로 지정합니다.
4. Present 모드에서 세 화면의 순환 이동을 확인합니다.
5. 공유 권한을 `링크가 있는 모든 사용자 — 보기 가능`으로 설정합니다.
6. 공유 URL을 README의 `Figma 링크` 섹션에 추가합니다.

공유 링크가 실제로 생성되기 전에는 README 체크리스트의 Figma 관련 항목을
완료로 변경하지 않습니다.
