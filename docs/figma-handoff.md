## 컴포넌트 후가공 우선순위

1. 주요 버튼 문구를 실제 텍스트 레이어로 교체
2. 진행률, 타이머, 안전 안내를 실제 텍스트·벡터로 교체
3. `잠시 쉬기/계속하기`를 두 상태 Variant로 구성
4. 몸 상태 3개 항목을 선택/비선택 Variant로 구성
5. 배지와 연속 기록을 재사용 가능한 컴포넌트로 구성
