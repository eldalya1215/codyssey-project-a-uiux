# 디자인 시스템

## 색상

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `color-primary` | `#F47B5B` | 주요 버튼, 강조, 진행 상태 |
| `color-background` | `#FFF7EF` | 전체 배경 |
| `color-support` | `#7FAF9A` | 안전 정보, 보조 상태 |
| `color-text` | `#24313D` | 제목과 본문 |

## 레이아웃

- 기준 화면 비율: 모바일 9:16
- 콘텐츠 좌우 여백: 화면 너비의 약 6%
- 카드 모서리: 크게 둥근 형태로 통일
- 핵심 행동: 화면당 주요 버튼 1개
- 버튼 최소 높이: 56px 이상 권장

## 접근성

- 본문과 배경은 충분한 명도 대비를 유지함
- 상태는 색상만으로 구분하지 않고 아이콘과 문구를 함께 사용함
- 50대 사용자를 고려해 작은 보조 문구를 최소화함
- 운동 중 통증 발생 시 중단 안내를 항상 노출함

## 화면 일관성

- 세 화면에서 동일한 인물, 의상, 실내 환경을 유지함
- 코랄색은 주요 행동과 성취 상태에만 사용함
- 세이지 그린은 안전 정보와 긍정적 상태에 사용함
- 제목, 카드, 버튼의 시각적 위계를 모든 화면에서 동일하게 유지함
