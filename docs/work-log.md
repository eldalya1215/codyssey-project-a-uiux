## 1차 화면 — 오늘의 운동

### 목적

사용자가 고민하지 않고 오늘 수행할 운동 하나를 바로 시작하도록 구성함.

### 관찰 결과

- 한글 제목과 주요 버튼이 선명하게 생성됨
- 운동 시간과 무릎 부담 정보의 위계가 명확함
- 인물의 다리와 의자 표현이 자연스러움

### 후속 보완

- Figma에서 실제 폰트로 텍스트를 다시 입력해 편집 가능 상태로 전환 필요
- 상단 격려 문구가 요구사항에 없으므로 최종 프로토타입에서 유지 여부 검토 필요

## 2차 화면 — 운동 진행

### 개선한 프롬프트

첫 화면을 스타일 참조로 제공하고 동일한 인물, 팔레트, 카드, 타이포그래피를 유지하도록 명시함.

### 관찰 결과

- 동일 인물과 실내 환경이 유지됨
- 진행률, 남은 시간, 이전·일시정지·다음 동작이 구분됨
- 통증 시 중단 안내가 눈에 띄게 배치됨

### 후속 보완

- 실제 프로토타입에서는 일시정지 버튼의 상태 변화를 별도 컴포넌트로 제작 필요
- 이미지 속 타이머와 진행률은 Figma에서 실제 텍스트와 벡터로 교체 필요

## 3차 화면 — 완료 및 보상

### 개선한 프롬프트

앞선 두 화면을 스타일 참조로 사용하고 과도한 축하 효과 없이 배지, 연속 운동, 몸 상태 기록을 강조함.

### 관찰 결과

- 동일 인물과 브랜드 색상이 유지됨
- 배지와 7일 연속 기록이 명확함
- 운동 후 상태 입력과 다음 행동이 한 화면에 정리됨

### 후속 보완

- 배지 도형의 의미를 더 명확한 발자국 또는 새싹 아이콘으로 수정 검토
- 몸 상태 선택 버튼의 선택·비선택 상태를 Figma 컴포넌트로 정의 필요
